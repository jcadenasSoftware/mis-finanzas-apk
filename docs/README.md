# Xpendz — Documentación Oficial

Este directorio centraliza toda la documentación del proyecto Xpendz: publicación en tienda, aspectos legales, modelo de monetización, identidad visual y proceso de lanzamiento.

---

## Estructura de carpetas

### `play-store/`
Documentación para la publicación y mantenimiento en Google Play Store: ficha de la aplicación, sección Data Safety, clasificación de contenido, acceso a la app para revisores y control de versiones.

### `legal/`
Documentos legales obligatorios: Política de Privacidad, Términos y Condiciones, y el proceso de solicitud de eliminación de cuenta de usuario.

### `premium/`
Definición del modelo de monetización freemium: especificaciones del plan Premium, límites del plan gratuito, estrategia de publicidad con AdMob y hoja de ruta de monetización.

### `branding/`
Identidad visual y recursos gráficos de Xpendz: directrices de marca, assets requeridos por Play Store y capturas de pantalla oficiales.

### `release/`
Proceso de lanzamiento y seguimiento: checklist previo a cada publicación y plan de acciones post-lanzamiento.

---

## Convenciones

- Las **carpetas** se nombran en inglés, en minúsculas con guiones.
- Los **archivos** usan nombres descriptivos en PascalCase o con prefijo numérico cuando el orden importa.
- El campo `## Estado` de cada documento refleja su madurez: `En preparación`, `En revisión` o `Aprobado`.
- El campo `## Última actualización` debe actualizarse manualmente al editar cada documento.
