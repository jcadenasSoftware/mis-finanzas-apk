## Purpose

This folder is **NOT technical documentation**. This folder stores **product knowledge** and **architectural knowledge** that could be lost over time.

Technical documentation describes what the code does. This knowledge base explains **why the product behaves the way it does**, how users think about money, and how the system interprets the domain.

## Content Examples

Future documents in this folder may include:

- How Xpendz thinks about money
- How Offline First works
- How synchronization works
- How categories work
- How Dashboard works
- How loans and credit work in the domain
- How budgets and goals relate to each other
- How multi-currency is modeled
- How the user mental model maps to the data model

## Audience

- New developers who need domain context.
- Product and UX people who need to understand system constraints.
- Future architects who need to preserve the reasoning behind the product.
